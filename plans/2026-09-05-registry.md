# Pure Registry Index Hub Implementation Plan

> 按用户要求在当前会话直接执行六个阶段。

**Goal:** 将旧模块源码仓迁移为纯元数据索引库。

**Architecture:** `modules/<id>.json` 为贡献源，`index.json` 为 CLI 聚合入口；构建与验证共享 Schema 和规则。main 上通过串行任务自动发布聚合结果。

**Tech Stack:** Node.js ESM、Ajv、ajv-formats、semver、GitHub Actions。

**Spec:** user-provided requirements

## 文件职责

- `package.json`、`package-lock.json`：只管理索引工具依赖。
- `schemas/registry-module.schema.json`、`schemas/registry-index.schema.json`：定义严格分片与 v2 聚合契约。
- `tools/verify.mjs`：读取分片、验证规则及可选的 npm 精确版本检查。
- `tools/build-index.mjs`：排序聚合、稳定时间戳和原子写入。
- `modules/*.json`：19 个官方模块清单；`index.json`：CLI 聚合入口。
- `.github/workflows/verify-pr.yml`、`.github/workflows/build-index.yml`：PR 门禁及主分支发布。
- `README.md`、`README.en.md`、`CONTRIBUTING.md`、`.vscode/settings.json`：消费与贡献说明、编辑器 Schema 关联。
- `test/registry.test.mjs`：隔离测试数据验证成功及失败路径。
